# Phase 8-4 — Customer access model

This checkpoint defines customer-access options for the paid Covered Call Simulator.

It is add-only and makes no dashboard or engine change.

Recommended MVP path:

- Start with a manual private beta list or password-gated hosted Streamlit MVP.
- Defer full automated subscription/login infrastructure until product validation.
- Treat payments and access control as separate implementation work.
- Keep the current simulator workflow intact while deployment is tested.
