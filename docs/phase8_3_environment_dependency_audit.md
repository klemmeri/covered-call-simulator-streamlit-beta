# Phase 8-3 — Environment and dependency audit

This checkpoint audits the local environment and expected deployment dependencies
for a Streamlit-compatible MVP deployment.

It is add-only and makes no dashboard or engine change.

The audit checks:

- Python version and platform.
- Core packages: pandas, numpy, matplotlib, streamlit.
- Required project files for deployment.
- Need for a deployment requirements file.
- Continued Streamlit MVP deployment direction.

Run:

`app\run_paid_simulator_phase8_3_environment_dependency_audit_check.py`
