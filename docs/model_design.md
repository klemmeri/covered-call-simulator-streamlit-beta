# Model Design

The project is organized into separate modules:

- config.py: simulation assumptions
- black_scholes.py: option pricing and delta
- price_paths.py: stock-price path generation
- strategy.py: covered-call entry rules
- portfolio.py: accounting and path-level results
- simulator.py: multi-path simulation engine
- reports.py: summary statistics and plots
- main.py: top-level script
