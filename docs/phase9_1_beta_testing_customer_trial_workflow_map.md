
# Phase 9-1 — Beta testing and customer-trial workflow map

This checkpoint starts Phase 9 by defining the private beta and customer-trial
workflow.

It is add-only and makes no dashboard or engine change.

The workflow covers:

- selecting beta testers
- sending onboarding instructions
- confirming disclaimer acceptance
- running the synthetic default scenario
- running optional historical scenarios
- collecting structured feedback
- reviewing results before broader access

Phase 9 is capped at six checkpoints:

1. Beta testing and customer-trial workflow map
2. Beta tester onboarding checklist
3. Customer feedback capture template
4. Beta safety and disclaimer review
5. Trial-run smoke-test script
6. Phase 9 completion handoff
