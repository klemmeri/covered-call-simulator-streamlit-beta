# Phase 4-2 — Market-Data Input Scaffold

This checkpoint starts the practical data/modeling upgrade path for the Covered Call Simulator.

It does not fetch live data and does not modify the Streamlit dashboard. Instead, it defines the local file contract for future real-data ingestion:

- underlying price CSV schema
- option-chain CSV schema
- sample input files
- validation rules
- next-step recommendations

## Design principle

Phase 4 should improve the model/data engine without destabilizing the customer-facing workflow completed in Phase 3.

The next logical checkpoint is Phase 4-3: a CSV validator for the sample underlying-price and option-chain file formats.
