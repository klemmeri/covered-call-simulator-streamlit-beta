# Phase 8-1 — Deployment and customer-access roadmap

This checkpoint starts Phase 8.

It is add-only and makes no dashboard or engine change.

Phase 8 is intended to move the local paid simulator toward a deployed customer product while preserving the development safeguards already established.

Planned Phase 8 checkpoints:

- Phase 8-1 — Deployment and customer-access roadmap
- Phase 8-2 — Deployment target decision
- Phase 8-3 — Environment and dependency audit
- Phase 8-4 — Customer access model
- Phase 8-5 — Hosted smoke-test plan
- Phase 8-6 — Deployment completion handoff

Standing commercial safeguards:

- Synthetic scenarios remain the default.
- Imported historical data remains explicit opt-in only.
- Historical data is scenario input, not a forecast.
- Regime detection is probabilistic guidance, not an oracle.
- Customer access and payment logic should remain separate from simulation logic.
