# Phase 9-3 — Customer feedback capture template

This checkpoint creates a structured feedback template for beta/customer trial
use.

It is add-only and makes no dashboard or engine change.

The template captures feedback on:

- first impression and positioning
- setup clarity
- synthetic default behavior
- historical opt-in behavior
- historical data as scenario input, not forecast
- risk wording
- result/chart/report clarity
- value proposition
- trust blockers
- highest-priority improvement request

Run:

`app\run_paid_simulator_phase9_3_customer_feedback_capture_template_check.py`
