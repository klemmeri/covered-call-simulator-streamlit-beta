# Phase 2 Assumption Alignment Fix

This fix aligns `scenario_assumptions.py` with the current deterministic Phase 2 price-path scaffold.

The assumption-consistency checker showed that the assumptions CSV used modeled returns that did not match the final returns generated by `scenario_price_paths.py`:

- Downtrend: assumption -6%, final path -8%
- Moderate Uptrend: assumption +4%, final path +5%
- Strong Rally: assumption +10%, final path +12%
- Volatile Whipsaw: assumption +1.5%, final path +2%

The corrected assumptions now use the current price-path returns as the source of truth:

- Downtrend: -8%
- Sideways Choppy: 0%
- Moderate Uptrend: +5%
- Strong Rally: +12%
- Volatile Whipsaw: +2%

This keeps the assumptions layer, price-path layer, payoff layer, and consistency checker aligned while Phase 2 remains a scaffold.
