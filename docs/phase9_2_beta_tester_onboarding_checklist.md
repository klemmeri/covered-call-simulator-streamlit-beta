# Phase 9-2 — Beta tester onboarding checklist

This checkpoint creates the beta tester onboarding checklist for customer-trial workflow.

It is add-only and makes no dashboard or engine change.

The checklist covers:

- inviting the tester;
- confirming risk understanding;
- explaining the synthetic default workflow;
- explaining historical mode as explicit opt-in only;
- providing private access instructions;
- running the first default scenario;
- collecting usability feedback;
- collecting wording/trust feedback.

Run:

`app\run_paid_simulator_phase9_2_beta_tester_onboarding_checklist_check.py`
