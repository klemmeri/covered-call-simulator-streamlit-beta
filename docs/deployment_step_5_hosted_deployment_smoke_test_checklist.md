# Deployment Step 5 — Hosted deployment smoke-test checklist

This checkpoint defines the manual smoke-test checklist to use after the app is
hosted on Streamlit Cloud or a Streamlit-compatible service.

It is add-only and makes no dashboard or engine change.

The checklist covers:

- hosted app launch
- synthetic default workflow
- explicit historical opt-in workflow
- historical data as scenario input, not forecast
- basic simulation run
- risk wording
- customer access control
- cross-browser sanity check

Run:

`app\run_deployment_step_5_hosted_deployment_smoke_test_checklist_check.py`
