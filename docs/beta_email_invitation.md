# Covered Call Simulator — Beta Tester Invitation

Subject: Covered Call Simulator beta test

Hi,

I am testing a new Covered Call Simulator public beta and would appreciate your feedback.

The app is designed to answer a practical question:

**If the market behaved in several different ways, would this covered-call setup help or hurt compared with simply holding the stock or ETF?**

Here is the beta link:

```text
https://configformapppy-nkcdrgmmzxvzlz89ck9m63.streamlit.app
```

Suggested test sequence:

1. Open the Overview page.
2. Run the default example on Setup & run.
3. Look at Latest results.
4. Try the Challenge page.
5. Try Preset comparison.
6. Review the Report and Help & assumptions pages.

This is still a beta. It is not trying to predict the market, and it does not yet include rolling covered calls or full Monte Carlo simulations. Right now it is a covered-call stress test using named market examples.

The most helpful feedback would be anything specific:

- Did any page fail to open?
- Was any wording unclear?
- Did any chart or text overlap?
- Did any button behave unexpectedly?
- Did the results make sense?
- Did anything sound too technical?

Screenshots are especially helpful if something looks wrong.
