# Phase 7-4 — Report export polish

This checkpoint defines a launch-readiness checklist for customer-facing report and table exports.

It is add-only and makes no dashboard or engine change.

The checklist covers:

- scenario summary report clarity;
- input echo completeness;
- risk and no-advice wording;
- historical-data caution;
- probabilistic regime wording;
- stable table headers and units;
- chart/export placement;
- predictable filenames;
- commercial wording safety.
